# DevOps Laboratory

Laboratorio personal de CI/CD para un ecosistema políglota.

## Stack
- **Backend:** Go (servicios cloud-native)
- **Frontend Web:** React
- **Móvil:** Kotlin + Kotlin Multiplatform (KMP)
- **Automatización:** Python
- **Legacy/Enterprise:** Java (soporte)

## Objetivos del laboratorio
1. Pipeline de CI para Go (lint, test, build, docker).
2. Pipeline de CI para React (lint, test, build).
3. Pipeline de CI para Kotlin/KMP (gradle build, test).
4. Pipeline de CD con Docker + GitHub Actions.
5. Documentar decisiones de arquitectura (ADRs).

## Tecnologías de CI/CD
- GitHub Actions
- Docker / Docker Compose
- (futuro) Kubernetes, Terraform
